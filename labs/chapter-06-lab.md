# Chapter 6 Lab: Virtual Machines: Deployment, Availability, and Disks

**Estimated time:** 25 minutes

## Exercise

Use Azure CLI to deploy a VM into a specific availability zone with az vm create --zone, then attach a Premium SSD managed disk and enable Azure Disk Encryption on it.

## Key takeaway

Availability sets, zones, and scale sets each protect against a different failure scope — the exam expects you to match the SLA and failure domain stated in the scenario to the correct construct.
