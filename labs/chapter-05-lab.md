# Chapter 5 Lab: Blob, Files, and Data Movement Tools

**Estimated time:** 20 minutes

## Exercise

Configure an Azure File Sync sync group linking an on-premises server endpoint to an Azure file share, enable cloud tiering, then use AzCopy to bulk-copy a local folder to a blob container with azcopy copy --recursive.

## Key takeaway

Blob lifecycle and object replication automate storage cost and resilience, but each has strict prerequisites the exam expects you to recall exactly.
