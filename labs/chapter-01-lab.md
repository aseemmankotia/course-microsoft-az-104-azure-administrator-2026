# Chapter 1 Lab: Microsoft Entra ID: Users, Groups, and Administrative Units

**Estimated time:** 25 minutes

## Exercise

In the Microsoft Entra admin center, create a dynamic security group with a membership rule based on department attribute, then create an administrative unit scoped to that department and delegate a Helpdesk Administrator role to it.

## Key takeaway

Administrative units and dynamic group rules let you scope and automate identity administration precisely — the exam tests whether you pick the narrowest correct scope.
