# Chapter 11 Lab: Monitoring, Backup, and Site Recovery

**Estimated time:** 20 minutes

## Exercise

Write a KQL query in a Log Analytics workspace to find the last 20 failed sign-in events, then create a Recovery Services vault and configure a daily backup policy with a 30-day retention for a virtual machine.

## Key takeaway

Monitoring and continuity questions test whether you can match a stated RPO/RTO or alert latency requirement to the correct Azure Monitor, Azure Backup, or Azure Site Recovery feature.
