# Chapter 8 Lab: Containers and Azure App Service

**Estimated time:** 25 minutes

## Exercise

Build and push a container image to Azure Container Registry, then deploy it to Azure Container Apps with az containerapp create referencing the ACR image, and configure a staging deployment slot in an App Service web app with a slot swap.

## Key takeaway

Choosing between ACI, Container Apps, ACR, and App Service comes down to orchestration needs and scaling triggers described in the scenario, not just 'it runs containers.'
