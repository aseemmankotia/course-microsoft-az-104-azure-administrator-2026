# Chapter 10 Lab: Load Balancing, Routing, and Hybrid Connectivity

**Estimated time:** 25 minutes

## Exercise

Deploy an internal Standard Load Balancer with a health probe and load balancing rule using Azure CLI, then create a private endpoint for an Azure Storage account and verify that its private DNS zone resolves to a private IP address instead of the public endpoint.

## Key takeaway

Layer 4 vs Layer 7 load balancing and service endpoints vs private endpoints are two of the most exam-tested networking distinctions — match the scenario's exact requirement to the correct layer or connectivity model.
