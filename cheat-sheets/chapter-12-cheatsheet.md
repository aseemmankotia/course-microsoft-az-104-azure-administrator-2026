## AZ-104 Exam Strategy Cheat Sheet

### Time Budget Basics
| Item | Value |
|---|---|
| Exam content time | 100 minutes |
| Question count | ~40-60 (varies by form) |
| Passing score | 700 / 1000 (scaled) |
| Case study block (if present) | ~5-7 linked questions, read scenario once |

### Pacing Checkpoints
| Progress | Elapsed time target |
|---|---|
| 25% of questions answered | ~25% of time used |
| 50% of questions answered | ~50% of time used |
| 75% of questions answered | ~75% of time used |
| Recalculate pace immediately after any case study block (it consumes disproportionate time) |

### Case Study Strategy
1. Read the full scenario once — note budget, region, compliance, existing resources.
2. Answer all linked questions using that single mental model.
3. Do not re-read the scenario per question.

### Elimination Technique
1. Discard options unrelated to the described technology/requirement.
2. Apply domain cue words to remaining options.
3. Flag if still uncertain; never leave blank.

### Domain Cue Words → Likely Direction
| Phrase | Points toward |
|---|---|
| "least administrative effort" | Managed/PaaS/automated solution |
| "minimize cost" | Cheapest tier meeting requirements |
| "highest availability / minimize downtime" | Zone/region redundancy |
| "least privilege" | Narrowest RBAC role/scope |
| "fastest to implement" | Built-in/native feature over custom build |

### Flag-and-Review Workflow
1. Answer every question with a best guess — never blank.
2. Flag uncertain ones as you go.
3. Complete the entire exam first.
4. Return only to flagged items with remaining time.
5. Change an answer only with a specific, concrete reason — not anxiety.

### Mixed Format Handling
| Format | Time adjustment |
|---|---|
| Multiple choice | Baseline pace |
| Drag-and-drop / build-list | +slightly more time, still cap and flag |
| Hot-area | +slightly more time, still cap and flag |

### Anxiety Management
- Never leave a question unanswered — a guess has nonzero chance, blank has zero.
- Don't flip answers repeatedly without new reasoning.
- Use flag-and-return instead of stalling on one question.
